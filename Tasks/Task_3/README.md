# Volunteer Opportunities for Students in India

A researched list of 18 volunteer opportunities, internships and fellowships for students in India, compiled on 19 October 2026 as part of the **InAmigos Foundation** task (Task 3).

Shout-out to **InAmigos Foundation** (@InAmigos Foundation) for the opportunity to build this resource.

## How to use
- Full data with filters: [`Volunteer_Opportunities_India.xlsx`](Volunteer_Opportunities_India.xlsx)
- Plain data: [`opportunities.csv`](opportunities.csv)
