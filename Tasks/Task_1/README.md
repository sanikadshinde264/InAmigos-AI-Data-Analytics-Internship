# 📊 Task 1: NGO Research & Data Collection 🔍

## 🎯 Objective

To research and collect information about 10 Non-Governmental Organizations (NGOs) working in India across different social sectors. This task aims to understand their areas of work, key initiatives, and contributions to society while developing research and data collection skills.

## 📝 Task Description

As part of the **AI & Data Analytics Internship at InAmigos Foundation**, this task involves researching 10 NGOs operating in India and organizing their information in a structured format.

The collected information helps understand how NGOs work in different social sectors, including education, healthcare, animal welfare, women empowerment, and environmental conservation.

## 📌 Task Requirements

- 🔍 Research 10 NGOs working in India.
- 🏢 Collect basic information about each organization.
- 🌐 Record the official website of each NGO.
- 📍 Identify the headquarters of each organization.
- 🎯 Document their areas of work and key initiatives.
- 📊 Organize the collected data in Excel, Google Sheets, or Word.
- ☁️ Save the original file in Google Drive.
- 💼 Share the completed work on LinkedIn or another social media platform, tag InAmigos Foundation, and take a screenshot.

## 📋 Data Collection Fields

The following information is collected for each NGO:

| Field | Description |
|---|---|
| NGO Name | Name of the organization |
| Official Website | Website URL of the NGO |
| Area of Work | Main social sector or cause |
| Headquarters | City and state of the organization |
| Key Initiatives | Major programs and activities |
